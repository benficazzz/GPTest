# WhatsApp local para Windows

[Baixar pacote ZIP](./whatsapp-luca7-windows.zip?raw=true)

Extraia a pasta e siga `LEIA-ME.md`. Execute, nesta ordem:

1. `1-instalar.cmd`: instala Python/Ollama/wacli e baixa o modelo local.
2. `2-vincular.cmd`: vincula sua conta do WhatsApp neste computador.
3. `3-testar-sem-enviar.cmd`: mostra sugestões sem enviar mensagens.
4. `4-responder-luca7.cmd`: habilita respostas automáticas somente para Luca7.

Mantenha o computador ligado e a janela aberta. Ctrl+C para parar.

O pacote contém um perfil de escrita e a identidade do contato permitido. Não contém histórico de mensagens, credenciais ou sessão do WhatsApp. Não adicione a pasta `private` ao Git.

Quatro testes com dados e serviços simulados passaram em Linux. A instalação e execução no Windows ainda precisam ser validadas. O modelo pode errar; confira o modo de prévia antes de habilitar envios.
